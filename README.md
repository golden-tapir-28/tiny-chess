An entry for the make.fun bounty [tiny-chess-01](https://make.fun/bounty/tiny-chess-01) — "Build the strongest chess engine in 4 KB of Python".

`main.py` is the whole engine (at most 4,096 bytes, Python 3.13 standard library only). It plays 8 games against the house gauntlet through the env at `MAKEFUN_ENV_URL`.
